Output Names

Shrink enables both output sizes by default. Uncheck either size to create only the other output. The choices also apply to files already queued and to downloads.

jep_and_jess_beyond_the_bayou_s01_e01_eng_bg_16x9_3840x2160.jpg creates jep_and_jess_beyond_the_bayou_s01_e01_eng_bg_16x9_1920x1080.jpg and jep_and_jess_beyond_the_bayou_s01_e01_eng_bg_1x1_3000x3000.jpg.

Honey, I blew up the images

Upscale converts exactly 1920x1080 JPGs to 3840x2160, 3000x3000, or both with Lanczos3. Both outputs are enabled by default. The square output scales the height to 3000px, then center-crops the width to 3000px. No sharpening is added.

The 16x9 name replaces 1920x1080 with 3840x2160; the square name changes 16x9_1920x1080 to 1x1_3000x3000. Sources without a size token receive the matching ratio and size suffix. JPEG metadata is retained with dimensions updated. Clear the queue before changing direction. Lanczos resamples existing detail; it does not generate new detail with AI.

Square Crop

The 1x1 output scales the 3840x2160 image until the height is 3000px, then center-crops the width down to 3000px.

Bulk Downloads

  • Select 100 or more JPGs together: 3840x2160 for Shrink, or 1920x1080 for Upscale.
  • One ready image downloads as one JPG.
  • Multiple ready images download together as a ZIP.
  • Skipped files stay listed with the reason they were skipped.

Desktop Apps

Unzip the Mac download, move HISTI v1.10.app to Applications, and open it. Supports Apple Silicon and Intel Macs running macOS 12 or later.

This release is not Apple-notarized. If macOS blocks the first launch, use System Settings > Privacy & Security > Open Anyway.

Windows: run HISTI.V1_10.Windows.Setup.exe, then open HISTI from the Start menu. For 64-bit Windows 10 or 11. The installer is unsigned.

Linux Mint: open HISTI.V1_10.Linux.amd64.deb in Package Installer, install it, then open HISTI from the Graphics menu. For 64-bit Mint 21.x and 22.x. No AppImage or FUSE setup is needed.

Offline web files V1.10 are also available.

Metadata

HISTI copies JPEG metadata segments into each resized output and updates common EXIF/XMP pixel dimension fields to match that output size.

Privacy

The browser version runs locally in the page. The images do not leave your computer.
